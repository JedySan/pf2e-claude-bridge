# PF2e Claude Bridge

Свой коннектор Claude ↔ Foundry VTT для системы **Pathfinder 2e**. Claude (через Claude Desktop и MCP)
читает мир, строит энкаунтеры и ведёт монстров в бою.

```
Claude Desktop ──stdio/MCP──▶ server/ (ваш компьютер) ──ws://127.0.0.1:47811──▶ модуль (вкладка ГМа) ──▶ мир Foundry
```

Репозиторий состоит из двух частей:

| Папка | Что это | Где работает |
|---|---|---|
| `module/` | Модуль Foundry | Ставится в Foundry, работает во вкладке ГМа |
| `server/` | MCP-сервер на Node.js | На компьютере, где запущен Claude Desktop |

## Установка

### 1. Модуль в Foundry

**Setup → Add-on Modules → Install Module**, в поле **Manifest URL** вставить:

```
https://github.com/JedySan/pf2e-claude-bridge/releases/latest/download/module.json
```

Включить **PF2e Claude Bridge** в мире. Обновления Foundry будет подтягивать сам.

### 2. MCP-сервер на компьютере

Нужен Node.js 20+.

```bash
git clone https://github.com/JedySan/pf2e-claude-bridge.git ~/pf2e-claude-bridge
cd ~/pf2e-claude-bridge/server && npm install
openssl rand -hex 16   # сгенерировать секрет
```

### 3. Конфиг Claude Desktop

Settings → Developer → **Edit Config**, в `mcpServers` добавить:

```json
"pf2e-bridge": {
  "command": "/opt/homebrew/bin/node",
  "args": ["/Users/<you>/pf2e-claude-bridge/server/index.js"],
  "env": {
    "PF2E_BRIDGE_SECRET": "<секрет>",
    "PF2E_BRIDGE_ORIGINS": "https://<адрес-вашего-foundry>"
  }
}
```

- `command` — полный путь к node (`which node`): Claude Desktop запускается с урезанным PATH.
- `PF2E_BRIDGE_ORIGINS` — адреса, с которых разрешено подключение (через запятую). Пусто — любые.
- `PF2E_BRIDGE_PORT` — порт, если 47811 занят (тогда поменять и в настройках модуля).

Полностью перезапустить Claude Desktop (Cmd+Q).

### 4. Связать модуль с сервером

В Foundry: **Configure Settings → Module Settings → PF2e Claude Bridge** → вставить тот же секрет.
Появится уведомление «Claude Bridge: подключено».

> Открывайте мир в **Chrome / Edge / Firefox**. Safari не пускает страницу с сервера к `127.0.0.1`.
> Chrome один раз спросит доступ к локальной сети — разрешить.

## Инструменты

**Мир и сцены**

| Инструмент | Что делает |
|---|---|
| `world-info` | Мир, система, активная сцена, кто онлайн, идёт ли бой |
| `list-scenes` | Список сцен с фильтром по названию |
| `get-scene` | Компактная сцена: токены в клетках, сторона, уровень, HP, КБ, состояния pf2e |
| `place-tokens` | Поставить токены актёров по клеткам (можно скрытыми — подкрепление) |
| `update-tokens` | Переместить, скрыть/показать, переименовать, сменить сторону |
| `delete-tokens` | Убрать токены со сцены |
| `create-combat` | Создать бой: видимые живые токены в трекер, по желанию бросить инициативу NPC |

**Энкаунтеры**

| Инструмент | Что делает |
|---|---|
| `search-compendium` | Поиск монстров по названию (рус./англ.), уровню, трейтам, редкости |
| `get-actor` | Компактный стат-блок: защиты, удары с MAP, способности, заклинания |
| `import-actor` | Импорт из компендиума в папку «Claude — энкаунтеры», Elite/Weak, несколько копий |
| `list-actors` | Актёры мира (в т.ч. только созданные для энкаунтеров) |
| `delete-actors` | Уборка; персонажей игроков не трогает |
| `encounter-budget` | XP и уровень угрозы по правилам PF2e, отдельно видимые и скрытые враги |

**Статусы, урон, чат**

| Инструмент | Что делает |
|---|---|
| `get-chat` | Новые сообщения чата с прошлой проверки: броски, исходы, цели |
| `get-queue` | Очередь событий, которые автоматика оставила для Claude |
| `set-condition` / `list-conditions` | Наложить/изменить/снять состояние с уровнем (Испуган 2 и т. п.) |
| `search-effects` / `apply-effect` / `remove-effect` | Эффекты pf2e (заклинания, эликсиры, способности) |
| `apply-damage` / `heal` | Урон с учётом сопротивлений/слабостей, лечение |
| `get-token-state` | HP, состояния и эффекты токенов |
| `send-chat-message` | Ответ в чат игры от имени Гриши или реплика NPC; шёпотом ГМу, игроку или всем |

## Автоматика

Работает сама, без Claude, — у активного ГМа (чтобы ничего не применялось дважды).
Каждая функция включается в **Module Settings → PF2e Claude Bridge**.

| Настройка | Что делает | По умолчанию |
|---|---|---|
| Авто: урон по целям | Урон из карточки — по выбранным целям, с IWR. Заклинания с базовым спасброском — с множителем по исходу (×0 / ×½ / ×1 / ×2) | только NPC |
| Авто: состояния от действий | Деморализовать → Испуган 1/2, Подсечка → Сбит с ног, Захват → Схвачен/Обездвижен, Вырваться → снять | вкл |
| Авто: спасброски NPC | Заклинание со спасброском применено к NPC-целям → их спасброски бросаются сами | вкл |
| Авто: поверженные | NPC с 0 HP — мёртв и повержен в трекере | вкл |
| Очередь для Claude | Исходы спасбросков, урон по небазовым спасброскам, действия без правила, сообщения с `@claude` | вкл |

Цели берутся из выделения (T) автора сообщения в момент броска.

**Связка с Claude**: напишите Claude «очередь» или «чат» — он заберёт накопленное и применит
нужные состояния и эффекты (например, «Страх: Мародёр — провал» → Напуган 2).

## Кузня существ

Если установлен модуль [PF2e Кузня существ](https://github.com/JedySan/pf2e-creature-forge),
Claude собирает существо по описанию по таблицам GM Core:

| Инструмент | Что делает |
|---|---|
| `forge-roles` | Роли-шаблоны (Громила, Солдат, Снайпер, Заклинатель…) |
| `forge-preview` | Посчитать числа без создания, с проверкой баланса |
| `forge-open` | Открыть у ГМа мастер с готовой заготовкой — ГМ проверяет и создаёт |
| `forge-create` | Создать сразу (если ГМ попросил без проверки) |

## Плашка «Гриша»

Вверху по центру экрана (видна только ГМу):

| Точка | Значит |
|---|---|
| 🟢 зелёная | Мост подключён к серверу в Claude Desktop |
| 🟡 мигает | Нет связи — Claude Desktop закрыт или перезапускается; модуль переподключается сам |
| 🔴 красная | Неверный секрет |
| ⚪ серая | Отключено в настройках модуля |

Фиолетовое число — сколько событий ждёт в очереди («напишите Claude „очередь“»).
Клик по плашке — переподключиться.

## Ассистент в чате игры — «@Гриша»

Напишите в чат Foundry `@Гриша …` (или `@claude …`) — сообщение уйдёт Claude в очередь.
Скажите Claude «очередь», и он ответит прямо в чат игры от имени Гриши (по умолчанию шёпотом ГМу),
а если просили — повесит статусы, найдёт монстров и т. п.

Имя ассистента и слова-обращения меняются в настройках модуля. Ответ можно направить всем,
конкретному игроку или озвучить от имени NPC (`send-chat-message`).

**Кто может обращаться** (настройка «Кто может обращаться к ассистенту»):

| Режим | Вопросы ГМа | Вопросы игроков |
|---|---|---|
| Только ГМ (по умолчанию) | ответ шёпотом ГМу | игнорируются |
| ГМ и игроки | ответ шёпотом ГМу | ответ виден всем |

## Обновление

- **Модуль** — Foundry сам предложит обновление (Setup → Add-on Modules → Update).
- **Сервер** — `cd ~/pf2e-claude-bridge && git pull && cd server && npm install`, затем перезапустить Claude Desktop.

Версии модуля и сервера должны совпадать: если модуль старее, Claude получит ошибку
«Модуль не знает команду…».

## Отладка

- Консоль браузера: `game.modules.get("pf2e-claude-bridge").api.status()`
- Логи сервера: Claude Desktop → Settings → Developer → pf2e-bridge → View logs

## Выпуск новой версии

Поднять `version` в `module/module.json` и `server/package.json`, закоммитить, затем:

```bash
cd ~/pf2e-claude-bridge && git pull && git tag v0.5.0 && git push origin v0.5.0
```

Workflow создаст релиз уже с файлами — Foundry не увидит «пустой» релиз.
(`gh release create` тоже работает, но первые ~минуту у релиза ещё нет `module.json`,
и обновление в Foundry в это время выдаст «No module manifest found».)

GitHub Actions соберёт `module.zip`, проставит версию и ссылку на архив в `module.json`
и создаст релиз с обоими файлами. Foundry увидит обновление сам.
